# Self-hosting P3 (parity) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fresh self-hosted install gets firmware releases, the PaulaNET driver disk and TOSEC data by itself, and the docs say how to add OpenRetro.

**Architecture:** Two new CRON_SECRET-guarded routes in `vercel.ts` (so our deployment and the self-host scheduler run the same code): `firmware-import` (daily, GitHub releases, signature-verified with the boards' own public key) and `tosec-fetch` (monthly, tosecdev.org Complete pack, only the 7 Amiga ADF DATs, a one-row state table). The PaulaNET ADF is built in a Docker build stage, sha-pinned, and stored on first start.

**Tech Stack:** Next 16 route handlers, drizzle + pg (P1), node:crypto ed25519, node:zlib (inflateRaw) for a small zip reader, Docker multi-stage (amitools 0.4.0 in a build stage only), vitest.

**Spec:** `docs/superpowers/specs/2026-10-16-selfhost-p3-parity-design.md`

## Global Constraints

- Generic: works on our Vercel deployment and on any self-host; cron routes go in `vercel.ts` (the self-host scheduler reads them from there); guarded by `Authorization: Bearer $CRON_SECRET`, failing CLOSED when unset.
- Firmware: accept a release only if the `.bin` sha256 equals the manifest's, `signatureFormat` is 2, `signingKeyId` is known, and the ed25519 signature verifies over `firmwareManifest({version, sequence, sha256, sizeBytes})` (`src/lib/firmware-manifest.ts`) -- the exact bytes boards verify. Keep the manifest's sequence. Never write anything for a failed check.
- Default firmware repo `stefanskotte/webadf`, overridable by `WEBADF_FIRMWARE_REPO`; GitHub REST API without a token; only tags `fw-<major>.<minor>.<patch>`; drafts and prereleases ignored.
- TOSEC: source `https://www.tosecdev.org/downloads`; import only entries matching `^TOSEC/Commodore Amiga - .* - \[ADF\] \(TOSEC-v[^)]*\)\.dat$` with the existing `importDat`; record the release only after every DAT imported.
- OpenRetro: never call openretro.org's (unpublished) metadata API.
- PaulaNET: the image build fails unless the built ADF's sha256 equals `PAULANET_DISK_SHA256` (`src/lib/paulanet-disk.ts`).
- Production DB: the new migration is applied to production only in the operator-gated rollout task.
- Never `git stash`, never `git add -A`; e2e on PORT 3100 only, one run at a time; never pattern-kill; `.env.local` holds production secrets -- never print it, never point a test at it.

## Review Focus

1. **GitHub API unavailable or rate-limited** (403 with `x-ratelimit-remaining: 0`, 5xx, network error) -- the cron logs one line and returns 200 with `{error}`; nothing is written; the next day retries. Pinned in Task 2.
2. **Release sequences with gaps** (TEST builds take sequences but never reach GitHub: 84 missing between 83 and 85) and **an older release appearing after a newer one** -- each imported with its own manifest sequence; nothing renumbered. Pinned in Task 2.
3. **tosecdev.org changes its pages, or a pack lacks Amiga ADF DATs** -- the state row records `failed: <reason>`, the previously imported release stays recorded, nothing half-recorded. Pinned in Task 4.
4. **A zip that uses deflate (method 8) or is zip64** -- deflate is read; zip64 is refused with a clear message (not a garbage parse). Pinned in Task 3.
5. **A fresh install where nobody has signed up yet** -- firmware import writes nothing (no publisher) and says it waits; it catches up on a later run. Pinned in Task 2.

`src/lib/firmware-verify.ts`:

```ts
import { createHash, verify } from 'node:crypto';
import { firmwareManifest, FIRMWARE_MAX_BYTES } from './firmware-manifest';
import { publicKeyFor, FIRMWARE_PUBLIC_KEYS } from './firmware-keys';

/** A GitHub release's manifest.json (firmware-github-release.ts), checked as a board would (spec P3 D2). */
export interface ReleaseManifest {
  version: string; semver: string; sequence: number; file: string; sha256: string;
  signature: string; signingKeyId: string; signatureFormat: number;
  notes?: string | null; security?: boolean;
}

export function parseReleaseManifest(j: unknown): ReleaseManifest | string {
  const o = j as Record<string, unknown>;
  const str = (k: string) => typeof o?.[k] === 'string' && (o[k] as string).length > 0;
  if (!o || !['version', 'semver', 'file', 'sha256', 'signature', 'signingKeyId'].every(str)
    || !Number.isInteger(o.sequence) || !Number.isInteger(o.signatureFormat)) {
    return 'manifest.json is missing version, semver, sequence, file, sha256, signature, signingKeyId or signatureFormat';
  }
  return {
    version: o.version as string, semver: o.semver as string, sequence: o.sequence as number, file: o.file as string,
    sha256: (o.sha256 as string).toLowerCase(), signature: o.signature as string, signingKeyId: o.signingKeyId as string,
    signatureFormat: o.signatureFormat as number,
    notes: typeof o.notes === 'string' ? o.notes : o.notes === null ? null : undefined,
    security: typeof o.security === 'boolean' ? o.security : undefined,
  };
}

export function verifyRelease(m: ReleaseManifest, bin: Buffer, keys = FIRMWARE_PUBLIC_KEYS): string | null {
  if (m.file !== 'wifi_floppy.bin') return `manifest names ${m.file}; only wifi_floppy.bin is a release image`;
  if (m.signatureFormat !== 2) return `signatureFormat ${m.signatureFormat}; boards accept 2`;
  if (bin.length > FIRMWARE_MAX_BYTES) return `image is ${bin.length} bytes; the limit is 2 MB`;
  const sha = createHash('sha256').update(bin).digest('hex');
  if (sha !== m.sha256) return `wifi_floppy.bin sha256 ${sha} is not the manifest's ${m.sha256}`;
  const key = publicKeyFor(m.signingKeyId, keys);
  if (!key) return `unknown signing key ${m.signingKeyId}`;
  const msg = firmwareManifest({ version: m.version, sequence: m.sequence, sha256: m.sha256, sizeBytes: bin.length });
  if (!verify(null, Buffer.from(msg, 'ascii'), key, Buffer.from(m.signature, 'base64'))) {
    return 'signature does not verify with the boards\' key';
  }
  return null;
}
```

`importRelease` in `src/lib/firmware-releases.ts`:

```ts
/**
 * Self-hosting P3 D3: a release imported from GitHub keeps the sequence its signature covers -- never
 * decidePublish's next number (TEST builds take sequences that never reach GitHub). The unique version
 * and sequence constraints make a second import of the same release a no-op.
 */
export async function importRelease(row: Omit<typeof firmwareReleases.$inferInsert, 'id' | 'publishedByUserId' | 'publishedAt'>, userId: string): Promise<boolean> {
  const inserted = await getDb().insert(firmwareReleases)
    .values({ ...row, id: randomUUID(), publishedByUserId: userId })
    .onConflictDoNothing()
    .returning({ id: firmwareReleases.id });
  return inserted.length === 1;
}
```

`src/lib/firmware-import.ts`:

```ts
import { inArray, asc } from 'drizzle-orm';
import { getDb } from '@/db';
import { firmwareReleases } from '@/db/schema/firmware';
import { user } from '@/db/schema/auth';
import { firmwareStore } from '@/lib/storage';
import { parseAllowlist } from '@/lib/superadmin-allowlist';
import { importRelease } from '@/lib/firmware-releases';
import { parseReleaseManifest, verifyRelease, type ReleaseManifest } from '@/lib/firmware-verify';
import { FIRMWARE_PUBLIC_KEYS } from '@/lib/firmware-keys';
import { webadfUserAgent } from '@/lib/user-agent';

export interface FirmwareImportResult { imported: string[]; skipped: { tag: string; reason: string }[]; waiting?: string; error?: string }
const TAG = /^fw-(\d+\.\d+\.\d+)$/;
const BOILERPLATE = /^wifi_floppy\.bin is the signed image/m;

export function notesFromBody(body: string | null): string | null {
  if (!body) return null;
  const m = BOILERPLATE.exec(body);
  const notes = (m ? body.slice(0, m.index) : body).trim();
  return notes || null;
}

interface GhRelease { tag_name: string; body: string | null; draft: boolean; prerelease: boolean; assets: { name: string; browser_download_url: string }[] }

export async function runFirmwareImport(opts: {
  repo?: string; fetchImpl?: typeof fetch; keys?: Readonly<Record<string, string>>; log?: (l: string) => void;
} = {}): Promise<FirmwareImportResult> {
  const repo = opts.repo ?? process.env.WEBADF_FIRMWARE_REPO ?? 'stefanskotte/webadf';
  const f = opts.fetchImpl ?? fetch;
  const log = opts.log ?? ((l) => console.log(l));
  const headers = { accept: 'application/vnd.github+json', 'user-agent': webadfUserAgent() };
  const result: FirmwareImportResult = { imported: [], skipped: [] };
  const db = getDb();

  const admins = parseAllowlist(process.env.SUPERADMIN_EMAILS);
  const [publisher] = admins.length
    ? await db.select({ id: user.id }).from(user).where(inArray(user.email, admins)).orderBy(asc(user.createdAt)).limit(1)
    : [];
  if (!publisher) { result.waiting = 'no super-admin has signed up yet; firmware import waits'; log(`firmware import: ${result.waiting}`); return result; }

  let releases: GhRelease[];
  try {
    const r = await f(`https://api.github.com/repos/${repo}/releases?per_page=100`, { headers });
    if (!r.ok) {
      const limited = r.status === 403 && r.headers.get('x-ratelimit-remaining') === '0';
      throw new Error(limited ? 'GitHub API rate limit reached' : `GitHub API answered ${r.status}`);
    }
    releases = await r.json() as GhRelease[];
  } catch (e) {
    result.error = (e as Error).message; log(`firmware import: ${result.error}; retrying at the next run`); return result;
  }

  const known = new Set((await db.select({ semver: firmwareReleases.semver }).from(firmwareReleases)).map((r) => r.semver));
  const candidates: { tag: string; m: ReleaseManifest; bin: Buffer; body: string | null }[] = [];
  for (const rel of releases) {
    const t = TAG.exec(rel.tag_name);
    if (!t || rel.draft || rel.prerelease || known.has(t[1])) continue;
    const skip = (reason: string) => { result.skipped.push({ tag: rel.tag_name, reason }); log(`firmware import: ${rel.tag_name}: ${reason}`); };
    const asset = (name: string) => rel.assets.find((a) => a.name === name)?.browser_download_url;
    const mUrl = asset('manifest.json');
    if (!mUrl) { skip('no manifest.json'); continue; }
    try {
      const m = parseReleaseManifest(await (await f(mUrl, { headers: { 'user-agent': headers['user-agent'] } })).json());
      if (typeof m === 'string') { skip(m); continue; }
      const binUrl = asset(m.file);
      if (!binUrl) { skip(`no ${m.file} asset`); continue; }
      const res = await f(binUrl, { headers: { 'user-agent': headers['user-agent'] } });
      if (!res.ok) { skip(`${m.file} download answered ${res.status}`); continue; }
      const bin = Buffer.from(await res.arrayBuffer());
      const bad = verifyRelease(m, bin, opts.keys ?? FIRMWARE_PUBLIC_KEYS);
      if (bad) { skip(bad); continue; }
      if (m.semver !== t[1]) { skip(`tag ${rel.tag_name} but manifest semver ${m.semver}`); continue; }
      candidates.push({ tag: rel.tag_name, m, bin, body: rel.body });
    } catch (e) { skip((e as Error).message); }
  }

  for (const c of candidates.sort((a, b) => a.m.sequence - b.m.sequence)) {
    const blobPath = `firmware/${c.m.version}.bin`;
    if (!(await firmwareStore.stat(blobPath))) await firmwareStore.put(blobPath, c.bin);
    const ok = await importRelease({
      version: c.m.version, semver: c.m.semver, sequence: c.m.sequence, sha256: c.m.sha256, sizeBytes: c.bin.length,
      blobPath, signature: c.m.signature, signingKeyId: c.m.signingKeyId, signatureFormat: c.m.signatureFormat,
      notes: c.m.notes !== undefined ? c.m.notes : notesFromBody(c.body), security: c.m.security ?? false,
    }, publisher.id);
    if (ok) { result.imported.push(c.m.version); log(`firmware import: ${c.tag} imported as ${c.m.version} (sequence ${c.m.sequence})`); }
    else result.skipped.push({ tag: c.tag, reason: 'version or sequence already present' });
  }
  return result;
}
```

```ts
import { open } from 'node:fs/promises';
import { inflateRawSync } from 'node:zlib';

/** Just enough zip for the TOSEC pack: central directory, stored (0) and deflate (8), no zip64. */
export interface ZipEntry { name: string; method: number; compressedSize: number; size: number; localOffset: number }

export async function listZip(path: string): Promise<ZipEntry[]> {
  const fh = await open(path, 'r');
  try {
    const { size } = await fh.stat();
    const tailLen = Math.min(size, 65_557);
    const tail = Buffer.alloc(tailLen);
    await fh.read(tail, 0, tailLen, size - tailLen);
    let e = -1;
    for (let i = tailLen - 22; i >= 0; i--) if (tail.readUInt32LE(i) === 0x06054b50) { e = i; break; }
    if (e < 0) throw new Error('not a zip file (no end of central directory)');
    const count = tail.readUInt16LE(e + 10), cdSize = tail.readUInt32LE(e + 12), cdOff = tail.readUInt32LE(e + 16);
    if (count === 0xffff || cdSize === 0xffffffff || cdOff === 0xffffffff) throw new Error('zip64 archives are not supported');
    const cd = Buffer.alloc(cdSize);
    await fh.read(cd, 0, cdSize, cdOff);
    const out: ZipEntry[] = [];
    let p = 0;
    for (let i = 0; i < count; i++) {
      if (cd.readUInt32LE(p) !== 0x02014b50) throw new Error('corrupt zip central directory');
      const nameLen = cd.readUInt16LE(p + 28), extra = cd.readUInt16LE(p + 30), comment = cd.readUInt16LE(p + 32);
      const entry = { name: cd.toString('utf8', p + 46, p + 46 + nameLen), method: cd.readUInt16LE(p + 10),
        compressedSize: cd.readUInt32LE(p + 20), size: cd.readUInt32LE(p + 24), localOffset: cd.readUInt32LE(p + 42) };
      if (entry.compressedSize === 0xffffffff || entry.localOffset === 0xffffffff) throw new Error('zip64 archives are not supported');
      out.push(entry);
      p += 46 + nameLen + extra + comment;
    }
    return out;
  } finally { await fh.close(); }
}

export async function readZipEntry(path: string, e: ZipEntry): Promise<Buffer> {
  const fh = await open(path, 'r');
  try {
    const lh = Buffer.alloc(30);
    await fh.read(lh, 0, 30, e.localOffset);
    if (lh.readUInt32LE(0) !== 0x04034b50) throw new Error(`corrupt zip local header for ${e.name}`);
    const start = e.localOffset + 30 + lh.readUInt16LE(26) + lh.readUInt16LE(28);
    const body = Buffer.alloc(e.compressedSize);
    await fh.read(body, 0, e.compressedSize, start);
    if (e.method === 0) return body;
    if (e.method === 8) return inflateRawSync(body);
    throw new Error(`${e.name}: unsupported zip compression method ${e.method}`);
  } finally { await fh.close(); }
}
```

```ts
import { mkdtemp, rm } from 'node:fs/promises';
import { createWriteStream } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { Readable } from 'node:stream';
import { pipeline } from 'node:stream/promises';
import { eq } from 'drizzle-orm';
import { getDb } from '@/db';
import { tosecFetch } from '@/db/schema/tosec';
import { importDat } from '@/lib/tosec-import';
import { listZip, readZipEntry } from '@/lib/zip-read';
import { AMIGA_ADF_DAT, TOSEC_DOWNLOADS, completePackLink, newestRelease } from '@/lib/tosec-fetch-parse';
import { webadfUserAgent } from '@/lib/user-agent';

export interface TosecFetchResult { status: 'imported' | 'up-to-date' | 'failed'; release?: string; dats?: number; entries?: number; reason?: string }

export async function readTosecFetchState() {
  const [row] = await getDb().select().from(tosecFetch).where(eq(tosecFetch.id, 'tosec'));
  return row ?? null;
}

async function record(fields: Partial<typeof tosecFetch.$inferInsert>) {
  await getDb().insert(tosecFetch).values({ id: 'tosec', lastAttemptAt: new Date(), ...fields })
    .onConflictDoUpdate({ target: tosecFetch.id, set: { lastAttemptAt: new Date(), ...fields } });
}

/** Monthly (vercel.ts): TOSEC's newest DAT pack, only the Amiga [ADF] DATs, via importDat (spec P3 D6-D7). */
export async function runTosecFetch(opts: { fetchImpl?: typeof fetch; tmpDir?: string; log?: (l: string) => void } = {}): Promise<TosecFetchResult> {
  const f = opts.fetchImpl ?? fetch;
  const log = opts.log ?? ((l) => console.log(l));
  const headers = { 'user-agent': webadfUserAgent() };
  const fail = async (reason: string): Promise<TosecFetchResult> => {
    await record({ lastResult: `failed: ${reason}` });
    log(`tosec-fetch: failed: ${reason}`);
    return { status: 'failed', reason };
  };
  try {
    const list = await f(TOSEC_DOWNLOADS, { headers });
    if (!list.ok) return fail(`${TOSEC_DOWNLOADS} answered ${list.status}`);
    const newest = newestRelease(await list.text());
    if (!newest) return fail(`no dated release on ${TOSEC_DOWNLOADS}`);
    const state = await readTosecFetchState();
    if (state?.release && state.release >= newest.date) {
      await record({ lastResult: 'up to date' });
      return { status: 'up-to-date', release: state.release };
    }
    const page = await f(new URL(newest.path, TOSEC_DOWNLOADS).toString(), { headers });
    if (!page.ok) return fail(`release page ${newest.path} answered ${page.status}`);
    const link = completePackLink(await page.text());
    if (!link) return fail(`no "DAT Pack - Complete" link on ${newest.path}`);
    const dir = await mkdtemp(join(opts.tmpDir ?? tmpdir(), 'tosec-'));
    try {
      const zipPath = join(dir, 'pack.zip');
      const res = await f(link, { headers });
      if (!res.ok || !res.body) return fail(`pack download answered ${res.status}`);
      await pipeline(Readable.fromWeb(res.body as never), createWriteStream(zipPath));
      const dats = (await listZip(zipPath)).filter((e) => AMIGA_ADF_DAT.test(e.name));
      if (dats.length === 0) return fail('the pack holds no Commodore Amiga [ADF] DAT');
      let entries = 0;
      for (const e of dats) {
        const r = await importDat((await readZipEntry(zipPath, e)).toString('utf8'));
        entries += typeof r === 'object' && r && 'count' in r ? Number((r as { count: number }).count) : 0;
      }
      const result = `imported ${newest.date} (${dats.length} DATs${entries ? `, ${entries} entries` : ''})`;
      await record({ release: newest.date, importedAt: new Date(), lastResult: result });
      log(`tosec-fetch: ${result}`);
      return { status: 'imported', release: newest.date, dats: dats.length, entries };
    } finally { await rm(dir, { recursive: true, force: true }); }
  } catch (e) {
    return fail((e as Error).message);
  }
}
```

`src/selfhost/paulanet.ts`:

```ts
import { readFile } from 'node:fs/promises';
import { createHash } from 'node:crypto';

/** Self-hosting P3 D5: the image carries the sha-pinned PaulaNET disk; first start stores it once. */
export async function ensurePaulanetDisk(opts: {
  adfPath: string; expectedSha256: string;
  has: (sha: string) => Promise<boolean>; put: (sha: string, bytes: Buffer) => Promise<void>; log?: (l: string) => void;
}): Promise<'stored' | 'present'> {
  if (await opts.has(opts.expectedSha256)) return 'present';
  const bytes = await readFile(opts.adfPath);
  const sha = createHash('sha256').update(bytes).digest('hex');
  if (sha !== opts.expectedSha256) throw new Error(`${opts.adfPath} is not the pinned PaulaNET disk (${sha})`);
  await opts.put(sha, bytes);
  opts.log?.('PaulaNET driver disk stored');
  return 'stored';
}
```
