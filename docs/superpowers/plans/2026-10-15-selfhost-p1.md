# Self-hosting P1 (runs without Vercel) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app runs on plain PostgreSQL with local-disk file storage and versioned migrations, while production keeps running on Neon and Vercel Blob.

**Architecture:** `getDb()` moves from `drizzle-orm/neon-http` to `drizzle-orm/node-postgres` over a `pg` Pool (Neon's pooled URL in production). `db.batch()` call sites become one `atomic()` helper that runs the same statements in a real transaction. The drizzle migration folder becomes the source of truth: proven against production's schema, production's journal written once, and `db:migrate` replaces `db:push`. `src/lib/storage.ts` keeps its five stores but each sits on a `BlobBackend` (Vercel Blob or local disk), chosen by whether `BLOB_READ_WRITE_TOKEN` is set; the local backend's uploads go through a signed app route.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs/` before touching route handlers), drizzle-orm 0.45 + `pg`, `@vercel/functions`, `@vercel/blob`, Docker (Postgres 18 on the Mac), vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-15-selfhost-p1-runs-without-vercel-design.md`

## Global Constraints

- One driver everywhere: `pg` + `drizzle-orm/node-postgres`; Pool max 5; registered with `attachDatabasePool` on Vercel (D1).
- `db.batch()` call sites keep all-or-nothing, now as one transaction; callers that read results get the same values (D2).
- Fresh database from `drizzle/` must be schema-identical to production (public + auth) except the journal (D3).
- Production's journal is written ONLY after the operator approves, by a script with a dry-run first (D4).
- `pnpm db:migrate` replaces `db:push`; `db:push` is removed from `package.json` (D5).
- Backend = `vercel-blob` when `BLOB_READ_WRITE_TOKEN` is set and non-empty, else `local` under `STORAGE_DIR` (default `./data/blobs`) (D7).
- Local writes: temp file + fsync + rename/link; keys match `^[a-z0-9][a-z0-9/._-]*$`, no `..`, no `//`, never end in `.meta.json`, resolved under `STORAGE_DIR` (D8).
- Local upload URL: `/api/blob-upload/<key>?exp=<unix s>&max=<bytes>&sig=<base64url>`, HMAC-SHA256 over `key\nexp\nmax` with an HKDF(`BETTER_AUTH_SECRET`, info `webadf-blob-upload`) key; 403 expired/bad signature, 413 over size, 400 `This blob already exists` on duplicate (D9).
- No data moves; production stays on Vercel Blob (D10). Everything is developed on the Mac's Docker (D11).
- e2e: `PORT=3100`, foreground, one run at a time (the default config shares production's database with other sessions).
- Never `pkill` by pattern; stop only your own PIDs or containers you started (`webadf-pg`).

## Review Focus

1. **A unique-violation inside a transaction (disk history's seq collision)** -- must still become `StaleHeadError`; with `pg` the error arrives wrapped (`DrizzleQueryError` -> `cause` = `DatabaseError` code `23505`). Pinned in Task 2's db test.
2. **A statement built from `getDb()` instead of `tx` inside `atomic()`** -- it would run OUTSIDE the transaction and survive a rollback. Pinned by Task 2's rollback test and a grep gate.
3. **Two concurrent uploads of the same key to the local backend** -- exactly one wins, the other gets "already exists", no partial file. Pinned in Task 4's contract test.
4. **An upload body larger than `max` with no or a lying `content-length`** -- refused with 413 while streaming, nothing stored. Pinned in Task 5.
5. **`BLOB_READ_WRITE_TOKEN` present but empty (e2e local run, Docker env files)** -- must select `local`, not crash in the SDK. Pinned in Task 4's selection test.

```bash
# A throwaway Postgres 18 for tests and the local e2e run (self-hosting P1).
# Only ever touches the container it names.
set -euo pipefail
NAME=webadf-pg PORT=55432
URL="postgresql://postgres:webadf@127.0.0.1:${PORT}/webadf"
case "${1:-}" in
  start)
    if ! docker ps --format '{{.Names}}' | grep -qx "$NAME"; then

      docker run -d --name "$NAME" -e POSTGRES_PASSWORD=webadf -e POSTGRES_DB=webadf -p "${PORT}:5432" postgres:18 >/dev/null

  url) echo "$URL" ;;
  psql) shift; docker exec -i "$NAME" psql -U postgres -d webadf "$@" ;;
  *) echo "usage: $0 start|reset|stop|url|psql" >&2; exit 2 ;;
```

```ts
import { Pool } from 'pg';
import { drizzle, type NodePgDatabase } from 'drizzle-orm/node-postgres';
import { attachDatabasePool } from '@vercel/functions';
// ...schema imports and `schema` exactly as today...

export type Db = NodePgDatabase<typeof schema>;

let _pool: Pool | null = null;
let _db: Db | null = null;

/**
 * One driver for every deployment (self-hosting P1, D1): node-postgres over a
 * small pool. Ours points at Neon's POOLED endpoint, which does the real
 * pooling, hence max 5; a self-host points at its own Postgres. On Vercel the
 * pool is attached so idle clients close before an instance suspends.
 */
export function getDb(): Db {
  if (!_db) {
    const url = process.env.DATABASE_URL;
    if (!url) throw new Error('DATABASE_URL is not set');
    _pool = new Pool({ connectionString: url, max: 5, idleTimeoutMillis: 10_000 });
    attachDatabasePool(_pool);
    _db = drizzle(_pool, { schema });
  }
  return _db;
}

/** Scripts and db tests only: lets the process exit. */
export async function closeDb(): Promise<void> {
  await _pool?.end();
  _pool = null;
  _db = null;
}
```

`src/db/atomic.ts`:

```ts
import { getDb, type Db } from './index';

export type Tx = Parameters<Parameters<Db['transaction']>[0]>[0];

/**
 * What db.batch() gave us on neon-http, as a real transaction (P1 D2): the
 * statements run in order, all or nothing, and each result comes back in
 * order. EVERY statement must be built from `tx` -- one built from getDb()
 * runs outside the transaction and survives a rollback.
 */
export async function atomic(build: (tx: Tx) => readonly PromiseLike<unknown>[]): Promise<unknown[]> {
  return getDb().transaction(async (tx) => {
    const out: unknown[] = [];
    for (const stmt of build(tx)) out.push(await stmt);
    return out;
  });
}
```

`scripts/db-baseline.ts`:

```ts
import { readMigrationFiles } from 'drizzle-orm/migrator';
import { sql } from 'drizzle-orm';
import { getDb, closeDb } from '@/db';

/**
 * Self-hosting P1 D4: record every migration in drizzle/ as applied, WITHOUT
 * running it, for a database whose schema already matches (production, built
 * by push + hand SQL before migrations were versioned). Writes exactly what
 * drizzle's migrator would: drizzle.__drizzle_migrations (hash, created_at).
 * Dry run unless { apply: true } / --apply. Refuses if a journal exists.
 */
export async function baseline({ apply }: { apply: boolean }): Promise<{ rows: { hash: string; createdAt: number }[] }> {
  const files = readMigrationFiles({ migrationsFolder: 'drizzle' });
  const rows = files.map((m) => ({ hash: m.hash, createdAt: m.folderMillis }));
  const db = getDb();
  const exists = await db.execute(sql`select to_regclass('drizzle.__drizzle_migrations') is not null as e`);
  if (exists.rows[0].e) throw new Error('journal already exists -- nothing to baseline');
  if (!apply) return { rows };
  await db.transaction(async (tx) => {
    await tx.execute(sql`create schema if not exists drizzle`);
    await tx.execute(sql`create table drizzle.__drizzle_migrations (id serial primary key, hash text not null, created_at bigint)`);
    for (const r of rows) {
      await tx.execute(sql`insert into drizzle.__drizzle_migrations (hash, created_at) values (${r.hash}, ${r.createdAt})`);
    }
  });
  return { rows };
}

if (process.argv[1]?.endsWith('db-baseline.ts')) {
  const apply = process.argv.includes('--apply');
  baseline({ apply })
    .then(({ rows }) => { console.log(`${apply ? 'WROTE' : 'would write'} ${rows.length} rows; last created_at ${rows.at(-1)?.createdAt}`); })
    .catch((e) => { console.error('db:baseline:', e.message); process.exitCode = 1; })
    .finally(() => closeDb());
}
```

`local.ts` -- one file per key, a sidecar `<file>.meta.json` holding `{ contentType }`; writes via a temp file in the same directory:

```ts
import { createWriteStream, promises as fs } from 'node:fs';
import { dirname, join, resolve, sep } from 'node:path';
import { randomUUID } from 'node:crypto';
import { Readable } from 'node:stream';
import { pipeline } from 'node:stream/promises';
import { assertKey, BlobExistsError, type BlobBackend } from './backend';
import { signUpload } from './upload-sig';   // Task 5; until then uploadUrl throws 'not yet'

export function localBackend(dir: string): BlobBackend {
  const root = resolve(dir);
  const pathOf = (key: string) => {
    assertKey(key);
    const p = resolve(root, key);
    if (!p.startsWith(root + sep)) throw new Error(`storage: invalid key ${JSON.stringify(key)}`);
    return p;
  };
  const metaOf = (p: string) => `${p}.meta.json`;

  return {
    label: 'Local disk',

    async put(key, body, { contentType, overwrite }) {
      const p = pathOf(key);
      await fs.mkdir(dirname(p), { recursive: true });
      const tmp = join(dirname(p), `.tmp-${randomUUID()}`);
      try {
        const src = body instanceof Uint8Array ? Readable.from([Buffer.from(body)]) : Readable.fromWeb(body as never);
        const out = createWriteStream(tmp, { flags: 'wx' });
        await pipeline(src, out);
        const fh = await fs.open(tmp, 'r'); await fh.sync(); await fh.close();
        await fs.writeFile(`${tmp}.meta.json`, JSON.stringify({ contentType }));
        if (overwrite) {
          await fs.rename(`${tmp}.meta.json`, metaOf(p));
          await fs.rename(tmp, p);
        } else {
          // link() fails with EEXIST atomically: exactly one concurrent writer wins.
          try { await fs.link(tmp, p); } catch (e) {
            if ((e as NodeJS.ErrnoException).code === 'EEXIST') throw new BlobExistsError(key);
            throw e;
          }
          await fs.rename(`${tmp}.meta.json`, metaOf(p));
        }
      } finally {
        await fs.rm(tmp, { force: true });
        await fs.rm(`${tmp}.meta.json`, { force: true });
      }
    },

    async get(key) {
      const p = pathOf(key);
      try {
        const st = await fs.stat(p);
        const meta = JSON.parse(await fs.readFile(metaOf(p), 'utf8').catch(() => '{}')) as { contentType?: string };
        const fh = await fs.open(p, 'r');
        return { stream: fh.readableWebStream({ type: 'bytes' }) as unknown as ReadableStream<Uint8Array>,
                 contentType: meta.contentType ?? 'application/octet-stream', sizeBytes: st.size };
      } catch (e) {
        if ((e as NodeJS.ErrnoException).code === 'ENOENT') return null;
        throw e;
      }
    },

    async head(key) {
      try { const st = await fs.stat(pathOf(key)); return { sizeBytes: st.size, uploadedAt: st.mtime }; }
      catch (e) { if ((e as NodeJS.ErrnoException).code === 'ENOENT') return null; throw e; }
    },

    async del(key) {
      const p = pathOf(key);
      await fs.rm(p, { force: true });
      await fs.rm(metaOf(p), { force: true });
    },

    async *list(prefix) {
      const base = resolve(root, prefix.replace(/\/$/, ''));
      if (!base.startsWith(root)) return;
      let names: string[] = [];
      try { names = await fs.readdir(base); } catch { return; }
      for (const n of names) {
        if (n.startsWith('.tmp-') || n.endsWith('.meta.json')) continue;
        const st = await fs.stat(join(base, n));
        if (st.isFile()) yield { key: `${prefix.replace(/\/$/, '')}/${n}`, uploadedAt: st.mtime };
      }
    },

    async uploadUrl(key, { maxBytes, ttlMs }) {
      assertKey(key);
      return signUpload(key, maxBytes, ttlMs);
    },
  };
}
```

```ts
import { isBlobAlreadyExists } from '@/lib/blob-upload';
import { assertKey, BlobExistsError, type BlobBackend } from './backend';

export function vercelBlobBackend(): BlobBackend {
  return {
    label: 'Vercel Blob',
    async put(key, body, { contentType, overwrite }) {
      assertKey(key);
      try {
        await put(key, body instanceof Uint8Array ? Buffer.from(body) : body, {
          access: 'private', contentType, addRandomSuffix: false, allowOverwrite: overwrite,
          ...(body instanceof Uint8Array ? {} : { multipart: true }),
        });
      } catch (err) {
        const message = err instanceof Error ? err.message : String(err);
        if (!overwrite && isBlobAlreadyExists(400, message)) throw new BlobExistsError(key);
        throw err;
      }
    },
    async get(key) {
      assertKey(key);
      const r = await get(key, { access: 'private', useCache: false });
      if (!r || r.statusCode !== 200) return null;
      const len = Number(r.headers?.get?.('content-length'));
      return { stream: r.stream, contentType: r.headers.get('content-type') ?? 'application/octet-stream',
               sizeBytes: Number.isFinite(len) && len > 0 ? len : null };
    },
    async head(key) {
      assertKey(key);
      try { const m = await head(key); return { sizeBytes: m.size, uploadedAt: new Date(m.uploadedAt) }; }
      catch (err) { if (err instanceof BlobNotFoundError) return null; throw err; }
    },
    async del(key) { assertKey(key); await del(key); },
    async *list(prefix) {
      let cursor: string | undefined;
      do {
        const page = await list({ prefix, cursor, limit: 1000 });
        for (const b of page.blobs) yield { key: b.pathname, uploadedAt: new Date(b.uploadedAt) };
        cursor = page.hasMore ? page.cursor : undefined;
      } while (cursor);
    },
    async uploadUrl(key, { maxBytes, ttlMs }) {
      assertKey(key);
      const validUntil = Date.now() + ttlMs;
      const token = await issueSignedToken({ pathname: key, operations: ['put'], maximumSizeInBytes: maxBytes, validUntil });
      const { presignedUrl } = await presignUrl(token, { operation: 'put', pathname: key, access: 'private', addRandomSuffix: false, allowOverwrite: false });
      return { url: presignedUrl, expiresAt: new Date(validUntil) };
    },
  };
}
```

```ts
import { createHmac, hkdfSync, timingSafeEqual } from 'node:crypto';

function signingKey(): Buffer {
  const secret = process.env.BETTER_AUTH_SECRET;
  if (!secret) throw new Error('BETTER_AUTH_SECRET is not set');
  return Buffer.from(hkdfSync('sha256', secret, Buffer.alloc(0), 'webadf-blob-upload', 32));
}
const mac = (key: string, exp: number, max: number) =>
  createHmac('sha256', signingKey()).update(`${key}\n${exp}\n${max}`).digest('base64url');

/** P1 D9: an upload URL on the app itself, for the local backend. */
export async function signUpload(key: string, maxBytes: number, ttlMs: number, now = Date.now()) {
  const exp = Math.floor((now + ttlMs) / 1000);
  const base = process.env.BETTER_AUTH_URL;
  if (!base) throw new Error('BETTER_AUTH_URL is not set');
  const u = new URL(`/api/blob-upload/${key}`, base);
  u.searchParams.set('exp', String(exp));
  u.searchParams.set('max', String(maxBytes));
  u.searchParams.set('sig', mac(key, exp, maxBytes));
  return { url: u.toString(), expiresAt: new Date(exp * 1000) };
}

export function verifyUpload(key: string, q: URLSearchParams, now = Date.now()):
  { ok: true; max: number } | { ok: false; status: 403 } {
  const exp = Number(q.get('exp')); const max = Number(q.get('max')); const sig = q.get('sig') ?? '';
  if (!Number.isInteger(exp) || !Number.isInteger(max) || max <= 0 || exp * 1000 < now) return { ok: false, status: 403 };
  const want = Buffer.from(mac(key, exp, max)); const got = Buffer.from(sig);
  if (want.length !== got.length || !timingSafeEqual(want, got)) return { ok: false, status: 403 };
  return { ok: true, max };
}
```

```ts
import { backend } from '@/lib/storage/select';
import { BlobExistsError, assertKey } from '@/lib/storage/backend';
import { verifyUpload } from '@/lib/storage/upload-sig';

/**
 * Where a browser or the CLI PUTs a disk image when storage is local (P1 D9).
 * Authorised by the URL's signature alone, like a presigned Blob URL. Answers
 * exactly as Vercel Blob does where the client cares: 403 = expired or bad
 * (the dropzone re-presigns once), 400 "This blob already exists" = already stored.
 */
export async function PUT(req: Request, ctx: { params: Promise<{ key: string[] }> }) {
  const b = backend();
  if (b.label !== 'Local disk') return new Response('not found', { status: 404 });
  const key = (await ctx.params).key.join('/');
  try { assertKey(key); } catch { return new Response('bad key', { status: 403 }); }
  const v = verifyUpload(key, new URL(req.url).searchParams);
  if (!v.ok) return new Response('expired or invalid upload URL', { status: 403 });
  const declared = Number(req.headers.get('content-length'));
  if (Number.isFinite(declared) && declared > v.max) return new Response('too large', { status: 413 });
  if (!req.body) return new Response('empty body', { status: 400 });

  let seen = 0;
  let over = false;
  const limited = req.body.pipeThrough(new TransformStream<Uint8Array, Uint8Array>({
    transform(chunk, c) {
      seen += chunk.byteLength;
      if (seen > v.max) { over = true; c.error(new Error('too large')); return; }
      c.enqueue(chunk);
    },
  }));
  try {
    await b.put(key, limited, { contentType: 'application/octet-stream', overwrite: false });
    return new Response(null, { status: 200 });
  } catch (e) {
    if (over) return new Response('too large', { status: 413 });
    if (e instanceof BlobExistsError) return new Response('This blob already exists', { status: 400 });
    throw e;
  }
}
```
