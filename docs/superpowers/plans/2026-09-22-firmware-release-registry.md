# Firmware Release Registry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the firmware version a board reports identify a real build, refresh it on every heartbeat, and give the Devices tab a registry to say truthfully which boards are behind.

**Architecture:** A hand-set semver in CMake gains an automatic git-hash suffix from a header regenerated on every build. `dc_report_status` carries that string in every heartbeat, so `devices.firmware_version` stops being write-once. A new global `firmware_releases` table, published to from the operator's Mac by a signing script, assigns each release a monotonic sequence; "behind" is a registry lookup, never a version comparison.

**Tech Stack:** Next.js App Router, Drizzle + Neon Postgres, Vercel Blob (private), Playwright, Vitest, Pico SDK 2.3.0 / CMake / Ninja, plain C host tests under clang.

**Spec:** `docs/superpowers/specs/2026-09-22-firmware-release-registry-design.md`

## Global Constraints

- **No device is updated by this increment.** No firmware is served, downloaded or flashed. If a task seems to need a device-facing firmware download route, it is out of scope — stop and re-read the spec's §4.
- **Version string maximum is 64 characters**, shared by the register route and the status route through one exported constant. Never hardcode 50 or 64 at a call site.
- **A `-dirty` version may never be published.** Refused in the publish script and again server-side.
- **The signing key is never read by server code.** `~/.webadf/firmware-signing-key` is touched only by `scripts/firmware-release.ts`, which runs on the operator's Mac.
- **`sequence` is assigned server-side** as `max(sequence) + 1`, never supplied by the client.
- **An unrecognised version is never reported as up to date.** Its own state, its own wording.
- **Firmware status body budget:** `DC_STATUS_BODY_BYTES` 640, `DC_STATUS_REQ_BYTES` 1152. Both buffers are `static` — read the stack note above `dc_enter_backoff` in `device_client.c` before adding any call site.
- **Never `git add -A`** when anything under `wifi-floppy/` is dirty; stage explicit paths. Re-run `git status` immediately before staging, every time.
- **e2e port is 4100** for this branch: `PORT=4100 BASE_URL=http://localhost:4100 pnpm e2e`.

```bash
grep -q "\"1.0.0+g${SHORT}-dirty\"" "$TMP/v2.h"; check "dirty tree is marked -dirty" $?

cmake -DSEMVER=1.0.0 -DSRC_DIR="$TMP/nogit" -DOUT="$TMP/v3.h" -P "$GEN" >/dev/null
grep -q '"1.0.0+nogit"' "$TMP/v3.h"; check "a non-repo builds as +nogit" $?

#    every build relinks the whole image.

BEFORE=$(stat -f %m "$TMP/v3.h"); sleep 1
```

- [ ] **Step 3: Write the generator**

Create `wifi-floppy/firmware/cmake/gen_version_header.cmake`:

```cmake
# Generates the firmware version header. Run with `cmake -P`, never included.
#
# Standalone so that it is testable without configuring the firmware build,
# and so that it can run as a BUILD step rather than a CONFIGURE step. That
# distinction is the whole point: generating at configure time means switching
# commits keeps the old hash until someone re-runs CMake, which is the same
# class of bug -- a version that does not change when the image does -- that
# this file exists to remove.
#
# Required: -DSEMVER=<x.y.z> -DSRC_DIR=<git work tree> -DOUT=<header path>

if (NOT DEFINED SEMVER OR NOT DEFINED SRC_DIR OR NOT DEFINED OUT)
  message(FATAL_ERROR "gen_version_header: SEMVER, SRC_DIR and OUT are all required")
endif ()

set(_suffix "+nogit")
find_package(Git QUIET)
if (GIT_FOUND)
  execute_process(
    COMMAND "${GIT_EXECUTABLE}" rev-parse --short HEAD
    WORKING_DIRECTORY "${SRC_DIR}"
    OUTPUT_VARIABLE _hash OUTPUT_STRIP_TRAILING_WHITESPACE
    ERROR_QUIET RESULT_VARIABLE _hash_rc)
  if (_hash_rc EQUAL 0 AND _hash)
    # --porcelain prints one line per changed path and nothing at all when the
    # tree is clean, so emptiness IS the cleanliness test.
    execute_process(
      COMMAND "${GIT_EXECUTABLE}" status --porcelain
      WORKING_DIRECTORY "${SRC_DIR}"
      OUTPUT_VARIABLE _dirty OUTPUT_STRIP_TRAILING_WHITESPACE
      ERROR_QUIET RESULT_VARIABLE _dirty_rc)
    if (_dirty_rc EQUAL 0 AND _dirty STREQUAL "")
      set(_suffix "+g${_hash}")
    else ()
      set(_suffix "+g${_hash}-dirty")
    endif ()
  endif ()
endif ()

set(_version "${SEMVER}${_suffix}")
set(_body "/* Generated by cmake/gen_version_header.cmake -- do not edit, do not commit. */\n")
string(APPEND _body "#ifndef WF_FIRMWARE_VERSION_H\n#define WF_FIRMWARE_VERSION_H\n")
string(APPEND _body "#define WF_FIRMWARE_VERSION \"${_version}\"\n")
string(APPEND _body "#endif\n")

# Write only on change. An unconditional file(WRITE) updates the mtime on
# every build, which would relink the whole image every time regardless of
# whether anything about the version actually moved.
set(_existing "")
if (EXISTS "${OUT}")
  file(READ "${OUT}" _existing)
endif ()
if (NOT _existing STREQUAL _body)
  file(WRITE "${OUT}" "${_body}")
  message(STATUS "firmware version: ${_version}")
endif ()
```

```c
// so an over-long body does not error -- the heartbeat simply stops, and only
// when an error string happens to be long. That is a state-dependent failure
// of the exact mechanism this increment adds, so the budget gets a test
// rather than a comment.
static void test_status_body_fits_at_maximum(void) {
    boot();
    static char long_err[DC_STATUS_ERR_BYTES];
    memset(long_err, 'E', sizeof long_err - 1);
    long_err[sizeof long_err - 1] = '\0';

    // Longest of everything the body can carry at once: 64-hex sha, a 64-char
    // disk id, a maximal error and a 64-char version (the server's bound).
    memset(c.mounted_sha256, 'a', 64); c.mounted_sha256[64] = '\0';
    memset(c.mounted_disk_id, 'b', 64); c.mounted_disk_id[64] = '\0';
    c.mounted_version = 4294967295u;
    static char long_ver[65];
    memset(long_ver, 'v', 64); long_ver[64] = '\0';

    fake_push_response("HTTP/1.1 204 No Content\r\n\r\n");
    CHECK(dc_report_status(&c, 2147483647, -200, long_err, long_ver),
          "a maximal body must still be sent, not silently dropped");
    const char *r = fake_last_request();
    CHECK(strstr(r, "\"firmwareVersion\"") != NULL,
          "the version survives a maximal body");
}
```

```ts
  id: text('id').primaryKey(),

  /** Server-assigned, max+1 at publish. Never supplied by a client. */
```

```ts
/**
 * Whether a device is running the current firmware.
 *
 * Pure, and deliberately NOT a version comparison (spec D2). The registry's
 * `sequence` is the ordering authority: a reported string is looked up, and a
 * string that is not in the registry is `unrecognised` -- never `current`.
 * Comparing semver instead would report a dirty bench build of `1.0.0` as up
 * to date against released `1.0.0`, which is the dishonesty this increment
 * exists to remove.
 */
export interface ReleaseRef {
  version: string;
  sequence: number;
  semver: string;
  security: boolean;
}

export type FirmwareState =
  | { kind: 'unknown' }
  | { kind: 'unrecognised'; version: string }
  | { kind: 'current'; version: string }
  | { kind: 'behind'; version: string; releasesBehind: number; latest: ReleaseRef };

export function firmwareState(
  reported: string | null,
  releases: readonly ReleaseRef[],
): FirmwareState {
  if (!reported) return { kind: 'unknown' };

  const match = releases.find((r) => r.version === reported);
  if (!match) return { kind: 'unrecognised', version: reported };

  // Highest sequence wins, computed rather than assumed, so an unsorted
  // query result cannot silently change the answer.
  const latest = releases.reduce((a, b) => (b.sequence > a.sequence ? b : a));
  if (match.sequence >= latest.sequence) return { kind: 'current', version: reported };

  return {
    kind: 'behind',
    version: reported,
    releasesBehind: releases.filter((r) => r.sequence > match.sequence).length,
    latest,
  };
}

export function countBehind(states: readonly FirmwareState[]): number {
  return states.filter((s) => s.kind === 'behind').length;
}
```

```ts
import { randomUUID } from 'node:crypto';
import { desc, max } from 'drizzle-orm';
import { getDb } from '@/db';
import { firmwareReleases } from '@/db/schema/firmware';
import type { ReleaseRef } from '@/lib/firmware-state';

export type PublishRefusalReason =
  | 'dirty' | 'duplicate_version' | 'semver_regression' | 'bad_semver';

export class PublishRefused extends Error {
  constructor(public readonly reason: PublishRefusalReason) {
    super(`firmware publish refused: ${reason}`);
    this.name = 'PublishRefused';
  }
}

export interface PublishInput {
  version: string; semver: string; sha256: string; sizeBytes: number;
  blobPath: string; signature: string; signingKeyId: string;
  notes: string | null; security: boolean;
}

const SEMVER_RE = /^(\d+)\.(\d+)\.(\d+)$/;

function semverParts(s: string): [number, number, number] {
  const m = SEMVER_RE.exec(s);
  if (!m) throw new PublishRefused('bad_semver');
  return [Number(m[1]), Number(m[2]), Number(m[3])];
}

/** -1, 0 or 1. Numeric per component -- "1.10.0" is above "1.9.0". */
function compareSemver(a: string, b: string): number {
  const [a1, a2, a3] = semverParts(a);
  const [b1, b2, b3] = semverParts(b);
  if (a1 !== b1) return a1 < b1 ? -1 : 1;
  if (a2 !== b2) return a2 < b2 ? -1 : 1;
  if (a3 !== b3) return a3 < b3 ? -1 : 1;
  return 0;
}

export async function publishRelease(
  input: PublishInput,
  userId: string,
): Promise<{ id: string; sequence: number }> {
  if (input.version.endsWith('-dirty')) throw new PublishRefused('dirty');
  semverParts(input.semver);  // throws bad_semver

  const db = getDb();
  const existing = await db
    .select({ version: firmwareReleases.version, semver: firmwareReleases.semver,
              sequence: firmwareReleases.sequence })
    .from(firmwareReleases);

  if (existing.some((r) => r.version === input.version)) {
    throw new PublishRefused('duplicate_version');
  }
  for (const r of existing) {
    if (compareSemver(input.semver, r.semver) < 0) {
      throw new PublishRefused('semver_regression');
    }
  }

  const sequence = existing.reduce((m, r) => (r.sequence > m ? r.sequence : m), 0) + 1;
  const id = randomUUID();
  await db.insert(firmwareReleases).values({ ...input, id, sequence, publishedByUserId: userId });
  return { id, sequence };
}

export async function listReleases(): Promise<ReleaseRef[]> {
  return getDb()
    .select({
      version: firmwareReleases.version, sequence: firmwareReleases.sequence,
      semver: firmwareReleases.semver, security: firmwareReleases.security,
    })
    .from(firmwareReleases)
    .orderBy(desc(firmwareReleases.sequence));
}

export type FirmwareReleaseRow = typeof firmwareReleases.$inferSelect;

export async function listReleasesFull(): Promise<FirmwareReleaseRow[]> {
  return getDb().select().from(firmwareReleases).orderBy(desc(firmwareReleases.sequence));
}
```

```ts
/**

  semver: z.string().min(1).max(32),
  sha256: z.string().regex(/^[0-9a-f]{64}$/),
  sizeBytes: z.number().int().positive(),
  blobPath: z.string().min(1).max(256),
  signature: z.string().min(1).max(256),
  signingKeyId: z.string().min(1).max(64),
  notes: z.string().max(4000).nullable().default(null),
  security: z.boolean().default(false),
});

export async function POST(request: Request) {
  const { userId } = await requireSuperAdmin();

  let raw: unknown;
  try { raw = await request.json(); } catch { raw = null; }
  const parsed = body.safeParse(raw);
  if (!parsed.success) {
    return Response.json({ error: 'invalid_body', detail: parsed.error.flatten() }, { status: 400 });
  }

  try {
    const { id, sequence } = await publishRelease(parsed.data, userId);
    return Response.json({ id, sequence }, { status: 201 });
  } catch (e) {
    if (e instanceof PublishRefused) {
      return Response.json({ error: e.reason }, { status: 409 });

    throw e;
  }
```

- [ ] **Step 2: Write the publish script**

Create `scripts/firmware-release.ts`:

```ts
/**
 * Builds, signs and publishes a firmware release (spec §3.4).
 *
 * The version is read out of the GENERATED HEADER, never from an argument, so
 * the published version is by construction the one inside the image. Passing
 * it in would reintroduce exactly the drift this increment removed.
 *
 * Usage: pnpm firmware:publish [--notes "..."] [--security]
 */
import { createSign, createHash, createPrivateKey, sign as edSign } from 'node:crypto';
import { execFileSync } from 'node:child_process';
import { readFileSync, existsSync } from 'node:fs';
import { homedir } from 'node:os';
import { join } from 'node:path';
import { put } from '@vercel/blob';

const repoRoot = join(import.meta.dirname, '..');
const headerPath = join(repoRoot, 'wifi-floppy/firmware/build/generated/wifi_floppy_version.h');
const uf2Path = join(repoRoot, 'wifi-floppy/firmware/build/wifi_floppy.uf2');
const keyPath = join(homedir(), '.webadf', 'firmware-signing-key');

function die(msg: string): never { console.error(msg); process.exit(1); }

// 1. Refuse a dirty tree. A build nobody can identify must not become the
//    thing a fleet is compared against.
const dirty = execFileSync('git', ['status', '--porcelain'], { cwd: repoRoot }).toString().trim();
if (dirty) die('Refusing to publish: the git work tree is dirty.\n' + dirty);

// 2. Read the version from the image's own header.
if (!existsSync(headerPath)) die(`No generated header at ${headerPath}. Run pnpm firmware:build first.`);
const m = /#define WF_FIRMWARE_VERSION "([^"]+)"/.exec(readFileSync(headerPath, 'utf8'));
if (!m) die(`Could not read WF_FIRMWARE_VERSION from ${headerPath}.`);
const version = m[1];
if (version.endsWith('-dirty')) die(`Refusing to publish a dirty build: ${version}`);
const semver = version.split('+')[0];

// 3. Hash the artifact.
if (!existsSync(uf2Path)) die(`No artifact at ${uf2Path}. Run pnpm firmware:build first.`);
const bytes = readFileSync(uf2Path);
const sha256 = createHash('sha256').update(bytes).digest('hex');

// 4. Sign the digest offline. Absent key = stop, never publish unsigned.
if (!existsSync(keyPath)) die(`No signing key at ${keyPath}. Run pnpm firmware:keygen first.`);
const key = createPrivateKey(readFileSync(keyPath));
const signature = edSign(null, Buffer.from(sha256, 'hex'), key).toString('base64');
const signingKeyId = process.env.WF_SIGNING_KEY_ID ?? `wf-release-${new Date().getFullYear()}`;

// 5. Upload to private blob storage.
const blobPath = `firmware/${version}.uf2`;
await put(blobPath, bytes, {
  access: 'private', contentType: 'application/octet-stream',
  addRandomSuffix: false, allowOverwrite: false,
});

// 6. Record it.
const args = process.argv.slice(2);
const notesIdx = args.indexOf('--notes');
const base = process.env.WEBADF_BASE_URL ?? 'https://webadf.vercel.app';
const res = await fetch(`${base}/api/admin/firmware/releases`, {
  method: 'POST',
  headers: { 'content-type': 'application/json', cookie: process.env.WEBADF_ADMIN_COOKIE ?? '' },
  body: JSON.stringify({
    version, semver, sha256, sizeBytes: bytes.byteLength, blobPath,
    signature, signingKeyId,
    notes: notesIdx >= 0 ? args[notesIdx + 1] : null,
    security: args.includes('--security'),
  }),
});
if (!res.ok) die(`Publish refused (${res.status}): ${await res.text()}`);
console.log(`Published ${version} as sequence ${(await res.json()).sequence}.`);
```

```ts
/** Every release this suite publishes carries this prefix. The teardown deletes
 *  by it, and nothing else may use it. */
export const E2E_RELEASE_PREFIX = '0.0.0-e2e';

export async function publishTestRelease(
  version: string, semver: string, opts: { security?: boolean } = {},
): Promise<void> {
  if (!version.startsWith(E2E_RELEASE_PREFIX)) {
    throw new Error(`e2e releases must start with ${E2E_RELEASE_PREFIX}, got ${version}`);
  }
  // Inserted directly rather than through the publish route: the route's
  // semver-regression rule is global, so a suite that published real-looking
  // versions would be ordered against whatever the operator last shipped.
  await getDb().insert(firmwareReleases).values({
    id: randomUUID(), version, semver, sequence: await nextTestSequence(),
    sha256: 'e'.repeat(64), sizeBytes: 1024, blobPath: `firmware/${version}.uf2`,
    signature: 'ZTJlLXRlc3Q=', signingKeyId: 'e2e', notes: null,
    security: opts.security ?? false, publishedByUserId: 'e2e',
  });
}

export async function cleanupTestReleases(): Promise<number> {
  const rows = await getDb().delete(firmwareReleases)
    .where(like(firmwareReleases.version, `${E2E_RELEASE_PREFIX}%`)).returning({ id: firmwareReleases.id });
  return rows.length;
}
```

`nextTestSequence()` takes `max(sequence) + 1` across the whole table, so a seeded release
is always newest and the fixture cannot reorder a real one.

**The semver used in the specs below is therefore `0.0.0-e2e.N`, not `1.0.0`.** Update the
