# Self-hosting P2 (the container) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `docker compose up -d` with one compose file and two `.env` settings runs webadf on any amd64/arm64 Docker host, upgrades with `pull && up -d`, and CI publishes the multi-arch image to GHCR.

**Architecture:** One image (Next standalone + a bundled `webadf-ctl` with subcommands `setup`, `start`, `scheduler`) used by three compose services, plus `postgres:18` and `caddy:2`. All logic that can be pure lives in `src/selfhost/*` with unit tests; the ctl is thin glue. Everything persistent is under one bind-mounted data folder.

**Tech Stack:** Next 16.3.2 (`output: 'standalone'`), Node 24 (image), pg 8 + drizzle-orm 0.45 (P1), esbuild (bundles the ctl), Caddy 2, Postgres 18, GitHub Actions (native amd64 + arm64 runners), vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-15-selfhost-p2-container-design.md`

## Global Constraints

- Generic: vanilla Docker Engine + Compose v2 (and Docker Desktop), amd64 and arm64; nothing host-, NAS- or distro-specific; no host paths except `WEBADF_DATA_DIR`.
- Developed and proven on the Mac's Docker (arm64) first; CI second; the openmediavault box (172.16.10.11) is acceptance only and operator-gated.
- Required `.env`: `WEBADF_URL` (https) **or** `WEBADF_DOMAIN`, and `WEBADF_ADMIN_EMAIL`. Optional: `WEBADF_DATA_DIR` (default `./data`), `WEBADF_HTTPS_PORT` (default `443`), `WEBADF_IMAGE_TAG` (default `latest`). No secrets in `.env`.
- Secrets (`better_auth_secret`, `cron_secret`, `pg_password`; 32 random bytes base64url) are created in `$WEBADF_DATA_DIR/secrets/` only when absent, mode 0600; an existing empty file is an error, never regenerated.
- Data folder layout: `$WEBADF_DATA_DIR/{postgres,blobs,caddy,secrets,backups}`. App runs as uid/gid 1000. Container paths: data folder at `/data`; `STORAGE_DIR=/data/blobs`.
- Only Caddy publishes a port: `${WEBADF_HTTPS_PORT:-443}:443`. Port 80 is never published. No plain HTTP.
- Our Vercel deployment must not change behaviour: standalone output only when `WEBADF_STANDALONE=1`; nothing in `vercel.ts` changes.
- Check failures print ONE line: what is wrong + the setting or command that fixes it; exit code 1.
- Never `git stash`, never `git add -A`; e2e on PORT 3100 only, one run at a time, foreground chunks under 9 minutes; never pattern-kill processes (stop servers by port).
- `.env.local` holds production secrets: nothing in this plan reads it inside Docker, and no step may run a stack against production's `DATABASE_URL`.

## Review Focus

1. **A data folder created by a different Postgres major or another install** -- postgres:18 keeps its cluster in `18/docker`, so an old `data/` cluster would be silently ignored and a fresh empty DB started, and the app would print a first-admin link as if new. Must fail in `setup`. Pinned in Task 1 (`checkPgData`).
2. **`pull && up -d` with nothing pending** -- must not take a backup or touch the schema; a second `up -d` is a no-op. Pinned in Task 3 (`migrationState`) and the Task 6 smoke.
3. **Two app containers starting at once** (`--scale app=2`, or a restart loop) -- migrations must serialise. Pinned in Task 3's db test.
4. **WEBADF_DOMAIN with a non-443 published port** -- Let's Encrypt TLS-ALPN cannot work; must fail with a message instead of a Caddy cert loop. Pinned in Task 1 (`resolveConfig`).
5. **A user who opens the site by a different host than WEBADF_URL** (IP vs name) -- uploads/sign-in fail; must log a clear warning once per host. Pinned in Task 4 (`originWarner`).

```ts
/** Self-hosting P2 (spec D3): the two required settings, validated, with the fix in every message. */
export interface SelfhostConfig {
  url: string; host: string; domain: string | null; adminEmail: string; superadmins: string; httpsPort: number;
}
export class ConfigError extends Error {}

export function resolveConfig(env: Record<string, string | undefined>): SelfhostConfig {
  const portRaw = env.WEBADF_HTTPS_PORT?.trim() || '443';
  if (!/^\d+$/.test(portRaw) || Number(portRaw) < 1 || Number(portRaw) > 65535) {
    throw new ConfigError(`WEBADF_HTTPS_PORT must be a port number (1-65535), got "${portRaw}"`);
  }
  const httpsPort = Number(portRaw);
  const domain = env.WEBADF_DOMAIN?.trim() || null;
  const rawUrl = env.WEBADF_URL?.trim() || (domain ? `https://${domain}` : '');
  if (!rawUrl) throw new ConfigError('Set WEBADF_URL in .env to the address you open webadf at, e.g. https://192.168.1.10 (or set WEBADF_DOMAIN to a public DNS name)');
  let u: URL;
  try { u = new URL(rawUrl); } catch { throw new ConfigError(`WEBADF_URL is not a valid address: "${rawUrl}" -- e.g. https://192.168.1.10`); }
  if (u.protocol !== 'https:') throw new ConfigError(`WEBADF_URL must start with https:// (Caddy serves TLS), got "${rawUrl}"`);
  if ((u.pathname !== '/' && u.pathname !== '') || u.search || u.hash) {
    throw new ConfigError(`WEBADF_URL must be just the address, without a path: use "${u.origin}"`);
  }
  if (domain) {
    if (u.origin !== `https://${domain}`) throw new ConfigError(`WEBADF_URL and WEBADF_DOMAIN disagree ("${u.origin}" vs "https://${domain}") -- set only WEBADF_DOMAIN`);
    if (httpsPort !== 443) throw new ConfigError('WEBADF_DOMAIN needs WEBADF_HTTPS_PORT=443: Let\'s Encrypt checks the domain on port 443');
  }
  const adminRaw = env.WEBADF_ADMIN_EMAIL?.trim();
  if (!adminRaw) throw new ConfigError('Set WEBADF_ADMIN_EMAIL in .env (it becomes the first admin)');
  if (!/^[^\s@]+@[^\s@]+$/.test(adminRaw)) throw new ConfigError(`WEBADF_ADMIN_EMAIL is not an email address: "${adminRaw}"`);
  const adminEmail = adminRaw.toLowerCase();
  return {
    url: u.origin, host: u.hostname, domain, adminEmail,
    superadmins: env.SUPERADMIN_EMAILS?.trim() || adminEmail, httpsPort,
  };
}
```

```ts
import { writeFileSync, unlinkSync } from 'node:fs';
import { join } from 'node:path';

/** Self-hosting P2 (spec D7). Each failure says what is wrong and what fixes it. */
export type CheckResult = { level: 'ok' | 'warn' | 'fail'; message: string };
export const GB = 1024 ** 3;
const ok = (message = ''): CheckResult => ({ level: 'ok', message });

export function checkFreeSpace(freeBytes: number, label: string): CheckResult {
  const gb = (freeBytes / GB).toFixed(1);
  if (freeBytes < GB) return { level: 'fail', message: `only ${gb} GB free on ${label}: webadf needs at least 1 GB (disk images are 880 KB each, plus their history) -- free space or set WEBADF_DATA_DIR to a bigger disk` };
  if (freeBytes < 5 * GB) return { level: 'warn', message: `${gb} GB free on ${label}: fine for now, but a big library with history wants more` };
  return ok();
}

export function checkWritable(dir: string, label: string): CheckResult {
  const probe = join(dir, `.webadf-write-probe-${process.pid}`);
  try {
    writeFileSync(probe, '');
    unlinkSync(probe);
    return ok();
  } catch {
    const uid = process.getuid?.() ?? 1000;
    return { level: 'fail', message: `${label} is not writable by uid ${uid}: run sudo chown -R 1000:1000 "$WEBADF_DATA_DIR/${label}"` };
  }
}

/** entries = names in data/postgres; hasLegacyPgVersion = data/postgres/data/PG_VERSION exists (pre-18 image layout). */
export function checkPgData(entries: string[], hasLegacyPgVersion: boolean): CheckResult {
  const majors = entries.filter((e) => /^\d+$/.test(e) && e !== '18');
  const found = majors[0] ?? (hasLegacyPgVersion ? 'pre-18' : null);
  if (found && !entries.includes('18')) {
    return { level: 'fail', message: `data/postgres holds a Postgres ${found} cluster but the image is Postgres 18 -- see docs/self-hosting.md, "Postgres major upgrade" (it is never upgraded automatically)` };
  }
  return ok();
}
```

```ts
import { randomBytes } from 'node:crypto';
import { mkdirSync, writeFileSync, readFileSync, existsSync, chownSync } from 'node:fs';
import { join } from 'node:path';

/** Self-hosting P2 (spec D4): generated once, never typed, never regenerated. */
export const SECRET_NAMES = ['better_auth_secret', 'cron_secret', 'pg_password'] as const;
export type SecretName = typeof SECRET_NAMES[number];
export class SecretError extends Error {}

export function ensureSecrets(dir: string, owner?: { uid: number; gid: number }): SecretName[] {
  mkdirSync(dir, { recursive: true, mode: 0o700 });
  if (owner) chownSync(dir, owner.uid, owner.gid);
  const created: SecretName[] = [];
  for (const name of SECRET_NAMES) {
    const p = join(dir, name);
    if (existsSync(p)) continue;
    writeFileSync(p, randomBytes(32).toString('base64url'), { flag: 'wx', mode: 0o600 });
    if (owner) chownSync(p, owner.uid, owner.gid);
    created.push(name);
  }
  return created;
}

export function readSecrets(dir: string): Record<SecretName, string> {
  const out = {} as Record<SecretName, string>;
  for (const name of SECRET_NAMES) {
    const p = join(dir, name);
    if (!existsSync(p)) throw new SecretError(`secrets/${name} is missing -- run docker compose up -d (the setup service creates it)`);
    const v = readFileSync(p, 'utf8').trim();
    if (!v) throw new SecretError(`secrets/${name} is empty -- restore it from a backup of the data folder (a new one would sign everyone out and lock out the database)`);
    out[name] = v;
  }
  return out;
}
```

```ts
import { readFileSync, readdirSync, mkdirSync, unlinkSync } from 'node:fs';
import { join } from 'node:path';
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
import { Client } from 'pg';
import { migrate } from 'drizzle-orm/node-postgres/migrator';
import { getDb } from '@/db';

/** Self-hosting P2 (spec D9): backed-up, locked, refusing a downgrade. */
export interface JournalEntry { when: number; tag: string }
export interface MigrationState { pending: string[]; newer: boolean; imageLatest: string }
export class MigrationRefused extends Error {}

const LOCK_KEY = 7_240_012; // arbitrary, constant: "webadf migrate"
const KEEP = 5;
const BACKUP_RE = /^\d{8}T\d{6}Z-before-.+\.dump$/;

export function migrationState(entries: JournalEntry[], dbLatest: number | null): MigrationState {
  const imageLatest = entries.at(-1)!.tag;
  const last = entries.at(-1)!.when;
  return {
    pending: entries.filter((x) => dbLatest === null || x.when > dbLatest).map((x) => x.tag),
    newer: dbLatest !== null && dbLatest > last,
    imageLatest,
  };
}

export function backupName(now: Date, firstPendingTag: string): string {
  const ts = now.toISOString().replace(/[-:]/g, '').replace(/\.\d{3}Z$/, 'Z');
  return `${ts}-before-${firstPendingTag}.dump`;
}

export function prunable(names: string[], keep: number): string[] {
  return names.filter((n) => BACKUP_RE.test(n)).sort().reverse().slice(keep).reverse();
}

const pgDump = async (url: string, file: string) => {
  await promisify(execFile)('pg_dump', ['--format=custom', `--file=${file}`, `--dbname=${url}`]);
};

export async function runStartupMigrations(opts: {
  url: string; migrationsFolder: string; backupDir: string;
  dump?: (url: string, file: string) => Promise<void>; log?: (line: string) => void;
}): Promise<{ applied: string[]; backup: string | null }> {
  const log = opts.log ?? ((l) => console.log(l));
  const journal = JSON.parse(readFileSync(join(opts.migrationsFolder, 'meta/_journal.json'), 'utf8')) as { entries: JournalEntry[] };
  const lock = new Client({ connectionString: opts.url });
  await lock.connect();
  try {
    await lock.query('select pg_advisory_lock($1)', [LOCK_KEY]);
    const has = await lock.query(`select to_regclass('drizzle.__drizzle_migrations') is not null as e`);
    const latest = has.rows[0].e
      ? Number((await lock.query('select max(created_at)::text as m from drizzle.__drizzle_migrations')).rows[0].m ?? NaN)
      : null;
    const state = migrationState(journal.entries, latest === null || Number.isNaN(latest) ? null : latest);
    if (state.newer) {
      throw new MigrationRefused(`the database has a migration newer than this image (which knows up to ${state.imageLatest}) -- use a newer image (WEBADF_IMAGE_TAG)`);
    }
    if (state.pending.length === 0) { log('migrations: up to date'); return { applied: [], backup: null }; }
    let backup: string | null = null;
    if (latest !== null) { // a fresh database has nothing to back up
      mkdirSync(opts.backupDir, { recursive: true });
      backup = join(opts.backupDir, backupName(new Date(), state.pending[0]));
      log(`migrations: backing up to ${backup} before ${state.pending.length} pending`);
      await (opts.dump ?? pgDump)(opts.url, backup);
      for (const old of prunable(readdirSync(opts.backupDir), KEEP)) unlinkSync(join(opts.backupDir, old));
    }
    try {
      await migrate(getDb(), { migrationsFolder: opts.migrationsFolder });
    } catch (e) {
      throw new MigrationRefused(`migration failed (${(e as Error).message}); the schema is unchanged${backup ? `; backup: ${backup}` : ''}`);
    }
    log(`migrations: applied ${state.pending.join(', ')}`);
    return { applied: state.pending, backup };
  } finally {
    await lock.query('select pg_advisory_unlock($1)', [LOCK_KEY]).catch(() => {});
    await lock.end();
  }
}
```

```ts
/** Self-hosting P2 (spec D8): one warning per host that does not match WEBADF_URL. */
export function originWarner(expected: string | undefined, log: (l: string) => void = (l) => console.warn(l)) {
  const seen = new Set<string>();
  return (req: Request) => {
    if (!expected) return;
    const host = req.headers.get('x-forwarded-host') ?? req.headers.get('host');
    if (!host) return;
    const proto = req.headers.get('x-forwarded-proto') ?? new URL(req.url).protocol.replace(':', '');
    const origin = `${proto}://${host}`;
    if (origin === expected || seen.has(origin)) return;
    seen.add(origin);
    log(`requests arrive as ${origin} but WEBADF_URL is ${expected} -- uploads and sign-in will fail; set WEBADF_URL to the address you open`);
  };
}

export const warnOnOrigin = originWarner(process.env.WEBADF_URL ? process.env.BETTER_AUTH_URL : undefined);
```

Note: `new URL('https://x.lan:443').origin` drops `:443`, and browsers send `Host: x.lan` for 443, so the default port compares equal.

```ts
/** Self-hosting P2 (spec D10). An invite's org is unused at sign-up (every user gets their own). */
export const BOOTSTRAP_ORG = 'bootstrap';
const ALPHABET = '0123456789ABCDEFGHJKMNPRSTUVWXYZ'; // same as src/lib/invites.ts (no I, L, O, Q)

export async function ensureBootstrapInvite(url: string, adminEmail: string): Promise<string | null> {
  const db = getDb();
  const [{ n }] = await db.select({ n: sql<number>`count(*)::int` }).from(user);
  if (n > 0) return null;
  const live = await db.select({ code: invites.code }).from(invites).where(and(
    eq(invites.orgId, BOOTSTRAP_ORG), isNull(invites.consumedAt), gt(invites.expiresAt, new Date()),
  )).limit(1);
  let code = live[0]?.code;
  if (!code) {
    code = Array.from({ length: 8 }, () => ALPHABET[randomInt(ALPHABET.length)]).join('');

  }
  return `Sign up as the first admin (use ${adminEmail}): ${url}/sign-up?invite=${code}`;
}
```

```ts
/** Self-hosting P2 (spec D11): the subset of cron vercel.ts uses -- numbers, '*', comma lists; UTC. */
export interface Cron { minute: number[]; hour: number[]; dom: number[] | null; month: number[] | null; dow: number[] | null }

function field(s: string, lo: number, hi: number): number[] | null {
  if (s === '*') return null;
  if (!/^\d+(,\d+)*$/.test(s)) throw new Error(`unsupported cron field "${s}"`);
  const v = s.split(',').map(Number);
  if (v.some((n) => n < lo || n > hi)) throw new Error(`cron field "${s}" out of range ${lo}-${hi}`);
  return v;
}

export function parseCron(expr: string): Cron {
  const f = expr.trim().split(/\s+/);
  if (f.length !== 5) throw new Error(`cron "${expr}" must have 5 fields`);
  const all = (lo: number, hi: number) => Array.from({ length: hi - lo + 1 }, (_, i) => lo + i);
  return {
    minute: field(f[0], 0, 59) ?? all(0, 59),
    hour: field(f[1], 0, 23) ?? all(0, 23),
    dom: field(f[2], 1, 31), month: field(f[3], 1, 12), dow: field(f[4], 0, 6),
  };
}

export function nextRun(c: Cron, after: Date): Date {
  const t = new Date(after.getTime());
  t.setUTCSeconds(0, 0);
  t.setUTCMinutes(t.getUTCMinutes() + 1);
  for (let i = 0; i < 366 * 24 * 60; i++) {
    if ((c.month === null || c.month.includes(t.getUTCMonth() + 1))
      && (c.dom === null || c.dom.includes(t.getUTCDate()))
      && (c.dow === null || c.dow.includes(t.getUTCDay()))
      && c.hour.includes(t.getUTCHours()) && c.minute.includes(t.getUTCMinutes())) return t;
    t.setUTCMinutes(t.getUTCMinutes() + 1);
  }
  throw new Error('no run within a year');
}
```

```ts
import { statfsSync, readdirSync, existsSync, mkdirSync, chownSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import { resolveConfig, ConfigError } from '@/selfhost/config';
import { checkFreeSpace, checkWritable, checkPgData, type CheckResult } from '@/selfhost/checks';
import { renderCaddyfile } from '@/selfhost/caddyfile';
import { ensureSecrets, readSecrets, SecretError } from '@/selfhost/secrets';
import { parseCron, nextRun } from '@/selfhost/cron';
import { config as vercelConfig } from '../vercel';

/** webadf-ctl: the container's entry (self-hosting P2). One line per failure, exit 1. */
const DATA = '/data';
const OWNER = { uid: 1000, gid: 1000 };
const say = (l: string) => console.log(`webadf: ${l}`);
function die(l: string): never { console.error(`webadf: ${l}`); process.exit(1); }
function report(r: CheckResult) { if (r.level === 'fail') die(r.message); if (r.level === 'warn') say(`warning: ${r.message}`); }
function free(dir: string) { const s = statfsSync(dir); return s.bavail * s.bsize; }

async function setup() {
  let cfg;
  try { cfg = resolveConfig(process.env); } catch (e) { if (e instanceof ConfigError) die(e.message); throw e; }
  for (const d of ['postgres', 'blobs', 'caddy', 'secrets', 'backups']) mkdirSync(join(DATA, d), { recursive: true });
  for (const d of ['blobs', 'backups']) chownSync(join(DATA, d), OWNER.uid, OWNER.gid);
  report(checkPgData(readdirSync(join(DATA, 'postgres')), existsSync(join(DATA, 'postgres/data/PG_VERSION'))));
  report(checkFreeSpace(free(DATA), 'the data folder'));
  const created = ensureSecrets(join(DATA, 'secrets'), OWNER);
  if (created.length) say(`created secrets: ${created.join(', ')}`);
  writeFileSync(join(DATA, 'caddy/Caddyfile'), renderCaddyfile(cfg));
  say(`setup ok -- ${cfg.url}`);
}

function env() {
  let cfg;
  try { cfg = resolveConfig(process.env); } catch (e) { if (e instanceof ConfigError) die(e.message); throw e; }
  let s;
  try { s = readSecrets(join(DATA, 'secrets')); } catch (e) { if (e instanceof SecretError) die(e.message); throw e; }
  process.env.DATABASE_URL = `postgresql://webadf:${encodeURIComponent(s.pg_password)}@db:5432/webadf`;
  process.env.BETTER_AUTH_SECRET = s.better_auth_secret;
  process.env.CRON_SECRET = s.cron_secret;
  process.env.BETTER_AUTH_URL = cfg.url;
  process.env.SUPERADMIN_EMAILS = cfg.superadmins;
  process.env.STORAGE_DIR = join(DATA, 'blobs');
  delete process.env.BLOB_READ_WRITE_TOKEN;
  return cfg;
}

async function waitForDb(url: string) {
  const { Client } = await import('pg');
  const deadline = Date.now() + 60_000;
  for (;;) {
    const c = new Client({ connectionString: url });
    try { await c.connect(); await c.end(); return; } catch (e) {
      const msg = (e as Error).message;
      if (/password authentication failed/.test(msg)) die('the database refuses the password in secrets/pg_password -- was data/postgres created by another install? (restore its secrets folder, or start with an empty data/postgres)');
      if (Date.now() > deadline) die(`the database at db:5432 did not answer within 60 s (${msg})`);
      await new Promise((r) => setTimeout(r, 1000));
    }
  }
}

async function start() {
  const cfg = env();
  for (const d of ['blobs', 'backups']) report(checkWritable(join(DATA, d), d));
  report(checkFreeSpace(free(DATA), 'the data folder'));
  await waitForDb(process.env.DATABASE_URL!);
  const { runStartupMigrations, MigrationRefused } = await import('@/selfhost/migrate');
  try {
    await runStartupMigrations({ url: process.env.DATABASE_URL!, migrationsFolder: '/app/drizzle', backupDir: join(DATA, 'backups'), log: say });
  } catch (e) { if (e instanceof MigrationRefused) die(e.message); throw e; }
  const { ensureBootstrapInvite } = await import('@/selfhost/bootstrap');
  const line = await ensureBootstrapInvite(cfg.url, cfg.adminEmail);
  if (line) say(line);
  const { closeDb } = await import('@/db');
  await closeDb();
  process.env.HOSTNAME = '0.0.0.0';
  process.env.PORT = '3000';
  await import('/app/server.js');
}

async function scheduler() {
  env();
  const jobs = (vercelConfig.crons ?? []).map((c) => ({ path: c.path, cron: parseCron(c.schedule) }));
  say(`scheduler: ${jobs.map((j) => j.path).join(', ')}`);
  for (const j of jobs) {
    (function arm(from: Date) {
      const at = nextRun(j.cron, from);
      setTimeout(async () => {
        const t0 = Date.now();
        try {
          const r = await fetch(`http://app:3000${j.path}`, { headers: { authorization: `Bearer ${process.env.CRON_SECRET}` } });
          say(`cron ${j.path}: HTTP ${r.status} in ${Math.round((Date.now() - t0) / 1000)} s`);
        } catch (e) {
          say(`cron ${j.path}: failed (${(e as Error).message}); next slot retries`);
        }
        arm(new Date());
      }, at.getTime() - Date.now());
    })(new Date());
  }
}

const cmd = process.argv[2];
const run = cmd === 'setup' ? setup : cmd === 'start' ? start : cmd === 'scheduler' ? scheduler : null;
if (!run) die('usage: webadf-ctl setup|start|scheduler');
run().catch((e) => die(`unexpected: ${(e as Error).stack ?? e}`));
```

(A `setTimeout` beyond 2^31-1 ms overflows; the longest gap here is 7 days = 6.0e8 ms, under the limit.)
